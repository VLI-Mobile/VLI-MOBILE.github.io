# Vita-Life Infusions — website starter

This is a static, free-hosting-ready website for Vita-Life Infusions — Mobile Services.

## Current status

The site intentionally uses conservative placeholder wording for the IV formulations because the current product labels and clinical information sheets have not yet been supplied.

Do NOT publish the site as final clinical/marketing material until:
- current product labels/information sheets are reviewed;
- the registered nurse's details and professional credentials are inserted;
- the screening form URL is inserted;
- the booking URL/workflow is inserted;
- service area, contact details and social links are inserted;
- Privacy Policy, Terms and Medical Disclaimer are finalised;
- the appropriate healthcare/regulatory professional has reviewed the clinical claims.

## Replace these placeholders

Search the files for:
- SCREENING_FORM_URL
- PHONE_NUMBER
- EMAIL_ADDRESS
- PRIVACY_POLICY_URL
- TERMS_URL
- MEDICAL_DISCLAIMER_URL
- [Registered Nurse Name]
- [Vita-Life Consultant Name]
- [Cape Town / service area]

## Free hosting

The files can be hosted free on GitHub Pages. Create a GitHub repository, upload index.html, style.css and script.js, then enable Pages from the repository's Settings > Pages.

A custom domain can be connected later.

## Booking workflow

Recommended:
1. Tally screening questionnaire
2. On submission, redirect to Calendly
3. Calendly sends the booking confirmation automatically

The current website contains a placeholder button until the actual Tally URL exists.
